# 无障碍

保障所有人都能顺畅使用界面，是组件库的基础设计原则。无论是通过键盘操作，还是依赖屏幕阅读器等辅助设备，都能获得完整的交互体验。组件与示例不会抹除默认焦点环，也不会为了极简设计牺牲色彩对比度。

## 键盘焦点指示

在使用键盘浏览时，清晰的焦点轮廓是定位当前操作目标的关键指引。组件库统一采用 `--astryx-focus-outline-*` 变量管理焦点环（Focus Ring）：宽度固定为 2px 实线，颜色遵循主题强调色 `--astryx-color-accent`，并保持 3px 的外侧偏移。

避免在全局样式中添加无条件的 `outline: none`。文档站仅在自带内部圆角聚焦态的表单控件上微调外部轮廓，防止产生多重视觉边框。

## 无文本按钮的可访问名称

若交互控件仅展示图标而无可见文本，屏幕阅读器将无法准确获知其功能。因此，纯图标按钮必须提供可访问名称（Accessible Name）：

- `IconButton` 组件的 `label` 属性为必填项，直接作为控件的可访问名称供屏幕阅读器朗读。
- `NavItem` 的 `label` 属性同样为必填项。
- 纯装饰性图形应添加 `aria-hidden="true"` 进行隐藏，避免直接使用图标类名或字符引起阅读歧义。

若某些说明文本需要被屏幕阅读器捕获但不在视觉排版中显式呈现，可使用 `@astryx-vue/core/VisuallyHidden` 提供的 `VisuallyHidden` 组件包裹。

## 浮层与弹窗焦点管理

弹窗与下拉菜单等浮层容器需要规范的焦点流转控制：

- **焦点捕获**：使用 `useFocusTrap` 将用户的 Tab 键导航范围限制在当前浮层容器内，防止焦点逃逸至背景页面。
- **焦点还原**：使用 `useRestoreFocus`，在浮层关闭后自动将焦点归还给触发打开它的源元素。
- **按键退出**：浮层响应 Escape 按键退出的逻辑由 `useDismiss` 的统一撤销栈维护，按照由内向外的顺序逐层关闭。
- **背景滚动锁定**：浮层激活期间，通过 `useScrollLock` 锁定底层视口的滚动。

## 屏幕阅读器播报与对话交互

- **状态通知**：部分异步操作（例如内容成功写入剪贴板），若仅有界面局部文字变化，屏幕阅读器可能无法感知。此时可通过 `useAnnounce` 触发动态播报；`useClipboard` 也支持配置 `announce` 参数，写入成功后主动播报反馈信息。
- **键盘导航模式**：列表与多列网格的上下左右方向键移动，分别由 `useListFocus`、`useGridRovingFocus` 与字母快速检索 `useTypeahead` 等组合式函数提供支持。
- **流式文本输出**：`ChatMessageList` 的底层角色声明为 `role="log"`。在文本流式生成期间保持 `isStreaming` 为 `true`，屏幕阅读器将在批次停顿或生成结束时播报内容，避免字符级频繁打断。

## 尊重减少动效配置

针对易产生晕动症或对动态位移敏感的用户，组件库动画规则严格遵循系统 `prefers-reduced-motion` 媒体查询。当用户开启「减少动效」选项时，大幅度的平移与缩放会自动禁用，仅保留淡入淡出过渡，详见 [动画](/themes/motion)。

各组件的具体无障碍特性与键盘交互请参考对应组件文档的无障碍说明，相关行为在测试用例中持续验证。
