# 模板

演练场（Playground）里的每个完整页面都是一个极佳的实践起点。在这里，你可以直观查看组件在真实业务场景中的排版组合方式。选中模板后，对应的完整 Vue 源码会直接呈现在内置编辑器中，右侧预览也会跟随当前主题与深色模式即时响应。

你还可以通过在链接后添加 `?template=` 参数直接跳转到指定模板，例如：[空白页模板](/playground/?template=blank)。

- **空白页模板（Blank）**：仅包含最基础的页面标题和一块干净的内容区，没有任何多余的导航或复杂组件，非常适合用来从零开始搭建你的新构想；
- **业务场景模板**：其余模板则预先组装好了后台仪表盘、AI 对话、任务看板等结构。当你需要类似结构时，直接基于它们二次修改往往能省下大把时间。
