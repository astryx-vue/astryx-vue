# 模板

演练场（Playground）中的完整页面模板展示了组件在实际场景中的排版组合方式。选中模板后，对应的完整 Vue 源码会在编辑器中展示，预览区域会随主题与深色模式即时更新。

可以通过在 URL 后追加 `?template=` 参数直接访问指定模板，例如：[空白页模板](/playground/?template=blank)。

- **空白页模板（Blank）**：仅包含基础标题和空白内容区，无多余导航或复杂组件，适合从零开始构建新页面。
- **业务场景模板**：预先组合了仪表盘、AI 对话流、任务看板等常见界面结构，可作为业务开发的起步参考。
