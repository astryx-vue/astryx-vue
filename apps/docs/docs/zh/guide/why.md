# 介绍

astryx-vue 是基于 Vue 3 实现的开源组件库，其视觉规范源自 Meta 的 [Astryx](https://github.com/facebook/astryx) 设计系统。原版文档位于 <https://astryx.atmeta.com>，基于 React 19 和 StyleX 构建。本项目由开源社区独立维护，旨在让 Vue 开发者无需切换技术栈，即可在日常项目中使用这套界面组件。

## 设计与实现方式

我们没有对 React 组件进行二次封装，而是使用 Vue 3 重新实现了整套界面的视觉规范与交互逻辑。组件库完整对齐了原版的四个基础：

1. **设计令牌（Token）**：统一间距、圆角与字号规范，语义清晰，便于全局维护。
2. **CSS 变量系统**：基于标准 `light-dark()` 语法，无需维护两套样式表即可在浅色与深色模式间切换，支持按需覆盖。
3. **动效（Motion）**：提供平缓的过渡动画与层级过渡；当用户开启系统级的「减少动效」选项时，会自动禁用大幅位移以保护阅读体验。
4. **组件覆盖**：覆盖基础按钮、表单输入、AI 对话流及管理后台布局等各类常用界面场景。

所有组件均遵循 Vue 3 标准规范：支持 Props、事件、插槽、`v-model` 和组合式函数（Composable），无需引入额外运行时桥接层。

## 架构划分

项目分为两个职责明确的软件包：

- `@astryx-vue/core`：核心组件库，包含所有 Vue 组件、常用组合式函数和组件结构样式。
- `@astryx-vue/themes`：主题包，提供 Neutral 等内置主题变量和排版样式规则。

组件库样式全部基于标准 CSS 编写，业务项目无需接入 StyleX 或额外的 CSS 预编译器。

## 图标与成套界面

组件库本身不强行捆绑图标库。在 `IconButton`（图标按钮）或 `NavItem`（导航项）等需要展示图标的场景中，可以直接传入 CSS 类名。你可以搭配 UnoCSS `presetIcons`、Tailwind、Iconify 或自定义 SVG 图标使用。

针对常见的 AI 交互与长文排版需求，组件库提供了开箱即用的组合模式。例如 `Chat`（对话流）、`Citation`（参考来源标记）和 `Markdown`（Markdown 渲染），避免在业务中重复拼装基础部件。

## 与上游原版的差异

绝大部分组件与原版一一对应。下表列出了本仓库新增、原版未包含的扩展能力。这些能力默认保持关闭，不会影响已有组件的默认行为：

| 特性 | 入口 | 说明 |
| --- | --- | --- |
| 自绘滚动条 | [`ScrollbarsProvider`](/components/scrollbars-provider) | 在应用外层包裹该 Provider 后，内部滚动区域会使用平滑的覆盖式滚动条；不包裹则保持系统原生滚动条，不会引入额外开销。 |

后续新增的扩展能力也会持续记录在此表中。
