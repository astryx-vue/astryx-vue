# 国际化

组件里需要句子的地方走语言包，不把中文或英文写死在每个调用点。支持的语言是 `en` 和 `zh-CN`，类型名是 `AstryxLocale`。

在应用根上提供一次。子组件用 `useAstryxLocale` 和 `useAstryxMessages` 读取。没提供时，语言是 `en`。

```ts
import { provideAstryxLocale } from '@astryx-vue/core/locale'

provideAstryxLocale('zh-CN')
```

`provideAstryxLocale`、`useAstryxLocale`、`useAstryxMessages`、`normalizeLocale`、`formatCalendarMonth` 和 `weekdayNames` 从 `@astryx-vue/core/locale` 引入。前四个也从 `@astryx-vue/core` 重新导出。

`normalizeLocale` 把 `zh` 和任何 `zh-` 开头的标签收成 `zh-CN`，其他值收成 `en`。

`AstryxMessages` 里有句子的部分是：`calendar`、`chat`、`citation`、`dateInput`、`markdown`、`multiSelector`、`nav`、`numberInput`、`pagination`、`selector`、`token`、`tokenizer`、`typeahead`。没有出现在这个类型里的组件，不会因为切换语言而改写自己的文案。那些文案由你传进去的 `label` 决定。

文档站的中英文是 VitePress 的两套页面，地址分别在 `/` 和 `/en/`。那是文档的语言，不是 `provideAstryxLocale`。组件示例会按当前文档语言调用 `provideAstryxLocale`。
