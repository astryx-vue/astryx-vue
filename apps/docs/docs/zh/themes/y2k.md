# Y2K（千禧复古极简主题）

Y2K 是一套致敬 2000 年代早期互联网先锋美学的主题。它采用清爽的长春花蓝与温暖的奶油色碰撞，并将所有组件的圆角全部收紧为坚决的纯直角（90 度硬朗直角边缘），视觉风格棱角分明、个性鲜明。

- **硬朗直角特性：** 按钮、卡片、输入框全部收成直边直角，呈现干脆利落的机械复古感。
- **字体配置：** 正文采用极具亲和力的几何无衬线字体 Poppins，展示型大字号搭配古典衬线字体 Crimson Text。
- **作用范围：** 仅对带有 `data-astryx-theme="y2k"` 的元素及其子树生效，不会污染全局 `:root`。

## 引入与使用

在项目中引入 Y2K 主题样式表：

```ts
import '@astryx-vue/themes/y2k.css'
```

在需要使用该风格的容器标签上加上主题标记即可：

```html
<div data-astryx-theme="y2k">
  <!-- 此容器内的所有 astryx-vue 组件都将自动呈现 Y2K 硬朗直角风格 -->
</div>
```
