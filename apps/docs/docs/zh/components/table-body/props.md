## 属性

`TableBody` 没有属性，行通过默认插槽传进来。

## 插槽

<div class="component-api-table" role="region" aria-label="TableBody 插槽" tabindex="0">
  <table>
    <thead>
      <tr><th>名称</th><th>说明</th></tr>
    </thead>
    <tbody>
      <tr><td><code>default</code></td><td><code>&lt;tbody&gt;</code> 里的数据行。必填。</td></tr>
    </tbody>
  </table>
</div>

## 原生属性

根元素是 `<tbody>`。

根元素会接收：

- HTML 属性。
- `aria-*` 属性。
- `data-*` 属性。
- `class`。
- `style`。
