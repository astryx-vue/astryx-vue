## DropdownMenuDivider Props

`DropdownMenuDivider` takes no props. It draws the same rule as `Divider`, so the theme variables documented on [Divider](/en/components/divider) apply. The rule element carries the `.astryx-dropdown-menu-divider` class, and `class` and `style` written on the component land on it.

The rule is a separator, so it is never a stop in the arrow-key order or in typeahead.
