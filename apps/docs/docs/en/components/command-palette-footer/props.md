## Props

`CommandPaletteFooter` takes no props.

## Slots

- `default`: replaces the three default hints. With no content, the footer shows the Navigate, Select, and Close hints, with `↑` `↓`, `↵`, and `Esc` badges. The text comes from the locale messages, so it is translated for you.
