# Templates

Each playground page is a starting point you can edit. Choosing one puts its source in the editor, and the preview follows the theme. Add `?template=` to open a page directly, for example the [blank page](/en/playground/?template=blank).

The blank page is a title and an empty content area. It has no navigation and no other chrome. Start there when every other template brings more structure than you want.

Templates are grouped by job. The name on the right opens that source in the playground.
