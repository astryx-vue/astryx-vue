## 二、关键技术决策与架构沉淀 (ADR 概要)

1. **坚持 Vue 习惯，不机械照搬 React**：
   - 上游使用的 `render prop` 和 `ref` 转发，在 Vue 版本中统一采用作用域插槽（Scoped Slots）与 `v-model`。
   - 上游基于 StyleX 的样式方案，统一转为 CSS 变量（CSS Custom Properties）与 CSS 原生分层（`@layer`）。

2. **坚决不用 `!important`**：
   - 组件库与主题内严禁使用 `!important`，确保组件使用方在业务代码中拥有完备的样式覆盖能力。
   - 编写了自动化静态检查脚本 `scripts/check-no-important.mjs` 并接入 `pnpm check`。

3. **独立的图标方案**：
   - 不照搬上游的 React 图标注册表。采用按需打包的 Iconify 机制（配合 `@iconify-json/*`），在组件层使用语义名，支持主题内自定义覆盖。

4. **自动化演练场像素级比对（`playground-diff`）**：
   - 沉淀了 `scripts/swarm/playground-diff.mjs`，通过在无头浏览器中自动配对文本与图标元素，数字化衡量位置、尺寸、字号、字重、颜色、背景色偏差。
